# Trecho HTML sugerido para o cabeçalho

Inserir imediatamente antes do link **Mais Direito**:

```html
<a href="https://www.jus9tecnologia.com.br/equipe/">Equipe</a>
```

Exemplo de bloco:

```html
<nav class="nav-secondary" aria-label="Navegação secundária">
  <a href="https://www.jus9tecnologia.com.br/equipe/">Equipe</a>
  <a href="https://www.jus9tecnologia.com.br/mais-direito/">Mais Direito</a>
  <a href="https://www.jus9tecnologia.com.br/comunidade/">Comunidade</a>
  <a href="https://www.jus9tecnologia.com.br/contato/">Contato</a>
  <a href="https://www.jus9tecnologia.com.br/privacidade/">Privacidade</a>
  <a href="https://jus9verde.jus9tecnologia.com.br/">Jus9 Verde</a>
  <a href="https://www.jus9tecnologia.com.br/lider-mvp">Pré-cadastro MVP</a>
</nav>
```

Se a página usa apenas links soltos no cabeçalho, aplicar a mesma lógica: colocar `Equipe` antes de `Mais Direito`.
