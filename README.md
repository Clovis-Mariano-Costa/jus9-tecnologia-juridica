## Estrutura

- `index.html` — landing page principal.
- `style.css` — identidade visual premium: azul profundo, dourado, sem pirâmide.
- `script.js` — menu mobile, ano automático e WhatsApp.

Cloudflare Pages conectado ao GitHub.

2. Enviar estes arquivos.

4. Framework preset: None.
5. Build command: vazio.
6. Output directory: `/` ou raiz do projeto.
7. Associar o domínio `jus9tecnologia.com.br`.
