# Jus 9 Tecnologia Jurídica — v2.1.2 Ajuste de acesso ao MVP

## Objetivo da revisão

Correção pontual solicitada após a versão v2.1.1: retirar o botão **Cadastro** que havia ocupado o espaço de destaque do acesso ao MVP na página inicial.

## Alterações realizadas

- Na Home (`index.html`), o botão principal do cabeçalho voltou a apontar para `mvp.html`.
- O texto do botão foi definido como **Acessar MVP**.
- O botão secundário **Ir para Cadastro** foi removido da área principal para não disputar atenção com o acesso ao MVP.
- A página `cadastro.html` permanece no pacote para uso posterior, mas não ocupa mais o botão de destaque da Home.

## Arquivos alterados

- `jus9-tecnologia-juridica/index.html`
- `jus9-tecnologia-juridica/README_v2_1_2_AJUSTE_ACESSO_MVP.md`
