# Jus 9 Tecnologia Jurídica — v2.1

## Tema
Dashboard, cadastro público, abertura de DAJ, foto do cliente, anexos, Workspace fotográfico e reforço de permissões.

## Alterações principais
- Preservada cópia base antes das alterações.
- Substituído no MVP o logo completo pela imagem eleita (`assets/jus9-logo-eleito.png`).
- Criada página `cadastro.html` no site institucional.
- Reformulada a abertura de DAJ em `app-atendimento-inicial.html`.
- DAJ passa a representar o cadastro inicial interno do cliente.
- Incluídos campos para foto pessoal do cliente e anexos na abertura.
- Reforçada auditoria obrigatória: criador, editor, data, hora e alterações.
- Atualizada a lógica de numeração: `DAJ-AAAAMM-000001`.
- Atualizada a página de perfis com delegação e aviso: execução se delega; responsabilidade não.
- Adicionada área de histórico de fotos no Workspace.

## Observação
Esta versão segue demonstrativa/estática. A implementação real exigirá backend, autenticação, banco, storage, logs, permissões e revisão jurídica/LGPD.
