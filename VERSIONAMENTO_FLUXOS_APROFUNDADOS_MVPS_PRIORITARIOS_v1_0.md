# Versionamento - fluxos aprofundados dos MVPs prioritarios v1.0

Data: 2026-05-31

## Objetivo

Transformar os paineis demonstrativos prioritarios em fluxos utilizaveis, preservando dados ficticios, persistencia local e revisao humana.

## Ambientes atendidos

- `DAJ` - Advogado / Defensor Publico;
- `DEJI` - Empresa / Juridico Interno;
- `DAA` - Professor / Academia;
- `DEJ` - Estudante;
- `DPJ` - Perito Judicial.

## Alteracoes

- adicionada trilha operacional propria por dossie;
- adicionado checklist com persistencia somente no navegador;
- adicionadas perguntas guiadas especificas nas paginas de IA;
- mantida a API compartilhada da Charlie Echo;
- ampliada a auditoria automatica dos MVPs.

## Limites

- nao usar dados reais;
- nao enviar checklist ao servidor;
- nao publicar segredo, cofre, credencial ou documento sigiloso;
- manter revisao humana obrigatoria.
