# Versionamento - Salas e Download Charlie Echo v4.7

Data: 04/06/2026

## Objetivo

Corrigir a leitura do chat da Charlie Echo e ensinar a interface a oferecer link clicavel de download quando gerar pacote PDF.

## Alteracoes

- Painel de salas deixa de ser fixo dentro da janela rolavel.
- Painel de salas passa a ficar acima da conversa, sem cobrir perguntas ou respostas.
- Botoes visiveis reduzidos para deixar a interface mais limpa.
- `Arquivar` e `Excluir` ficam dentro do menu `Mais`.
- `Transformar em pacote` foi simplificado para `Gerar PDF`.
- Ao gerar PDF, a Charlie baixa o arquivo e tambem exibe um link `Baixar PDF` dentro da conversa.
- Prompt enviado para a API reforca que arquivos gerados devem oferecer link clicavel de download.

## Funcionalidades preservadas

- Nova sala.
- Renomear sala.
- Arquivar sala.
- Excluir sala.
- Melhorar resposta.
- Memoria curta por sala.
- Resposta para pergunta anterior por texto.
- Geracao de PDF local.
