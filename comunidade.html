01 · Projeto

O Carne Hardware é um laboratório voluntário para ideias e protótipos locais seguros; ele não hospeda serviços públicos nem recebe testes destrutivos.

02 · Validação

A proposta API para Todos permanece em estudo, sem acesso irrestrito. Conexões precisam de identidade técnica verificável, consentimento, escopo e auditoria.

03 · Implantação

Serviços aprovados poderão migrar para servidores adequados ao software livre. Nenhuma migração de contas, dados, identidades ou permissões decorre automaticamente desta página.

Estado desta edição: vitrine pública de navegação e projeto, não constituição promulgada, licença aprovada, votação, anúncio de API operacional ou garantia de produção. Autoria institucional Jus 9, com contribuição de assistentes de IA e responsabilidade humana.
