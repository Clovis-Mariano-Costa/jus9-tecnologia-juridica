Jus 9 DAJ is a governed legal-workflow MVP. The demonstrated flow turns a fictional client intake into an auditable DAJ record, requests AI-assisted analysis in a new isolated room, returns feedback and human routing, queries official public case metadata by CNJ number, and links one DAJ to one case without inventing unavailable results.
