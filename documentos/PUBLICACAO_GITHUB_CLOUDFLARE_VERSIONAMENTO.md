# Publicação, GitHub, Cloudflare e Versionamento — Checklist Final

## GitHub

1. Criar repositório `jus9-tecnologia-juridica`.
2. Subir a pasta `jus9_site_v1_0`.
3. Criar branch principal `main`.
4. Usar commits por etapa:
   - Movimento 1
   - Movimento 2
   - Movimento 3
   - Manuais
   - Publicação

## Cloudflare Pages

1. Conectar repositório GitHub.
2. Build command: vazio, se site estático.
3. Output directory: `jus9_site_v1_0`.
4. Ativar HTTPS.
5. Conferir domínio `jus9tecnologia.com.br`.

## DNS

1. Confirmar nameservers Cloudflare.
2. Configurar registros necessários.
3. Confirmar HTTPS ativo.
4. Confirmar redirecionamento www, se desejado.
