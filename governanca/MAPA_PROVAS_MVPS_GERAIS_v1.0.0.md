# Mapa de Provas dos MVPs Gerais

## Decisao

Este mapa define o que cada MVP precisa provar antes de receber nova camada operacional, memoria real, Drive real, cofre, dado real ou promessa publica mais forte.

Regra central: todos os MVPs continuam demonstrativos, com dados ficticios, ate aceite humano e governanca propria.

## Criterios de leitura

- `Prova`: valor minimo que o MVP deve demonstrar.
- `Demo minima`: experiencia publica ou controlada que mostra esse valor.
- `Aceite`: verificacao objetiva para dizer que a prova funcionou.
- `Bloqueio`: aquilo que nao pode ser tratado como entregue.
