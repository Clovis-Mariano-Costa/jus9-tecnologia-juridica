# Memoria Charlie Echo

A memoria da Charlie Echo e separada em quatro classes:

- Permanente.
- Evolutiva.
- Temporaria.
- Conversacional.

Regra dura: memoria temporaria nao pode ser promovida automaticamente para memoria permanente.

Uso pretendido:

- Permanente: identidade, clausulas petreas, Constituicao, leis internas e regras aprovadas.
- Evolutiva: aprendizados aprovados, melhorias por MVP e ajustes homologados.
- Temporaria: contexto operacional de uma tarefa, sem promocao automatica.
- Conversacional: memoria curta de sala, com escopo limitado.
