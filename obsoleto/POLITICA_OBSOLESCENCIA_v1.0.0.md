# Politica de Obsolescencia

Um item so deve ser marcado como obsoleto quando houver motivo documentado.

Motivos aceitos:

- Substituido por versao nova.
- Risco de seguranca.
- Duplicidade documental.
- Mudanca de arquitetura.
- Erro historico preservado para auditoria.

Itens obsoletos nao devem ser usados como fonte ativa sem revisao humana.
